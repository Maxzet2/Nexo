# Проект по курсу Котлина

## Тема проекта: Приложение для локального ИИ

### Краткое описание:

Проект включает в себя сервер, который разворачивает локально модель, и клиент, с которого отправляется запросы к модели. Особенность заключается в простой и понятное первичной настройке и работе с моделями (на серваке лежат несколько моделей и пользователь допустим захотел использовать модель и при отправлении промпта весь жизненный цикл модели от и до идет самим серваком), возможность соединения клиента сервера по внешней сети (будет добавлена авторизация) и также будет добавлена возможность работы с не только текстовыми моделями (планируется генерация изображений, анализ изображений и возможно перевод и синтез речи. Качество будет зависеть от мощности сервера и от модели)

### Бизнес требования:

- Сервер хранит в себе модельки и при отправке промпта от клиента он запускает, обрабатывает и завершает жизненный цикл модели. Если задача комплексная, то пайплайн этой задачи управляется полностью сервером. 
- Управлять моделями можно либо от имени администратора (то есть с клиента войдя под логином администратора), либо напрямую на сервере. Пользователь может просто пользоваться моделями только по специальному контракту (то есть пользователю может только "писать текстовые вопросы" или "генерация изображения", но напрямую взаимодействовать с моделями не может)
- Возможность настройки MCP-сервера (некоторые модели могут работать в режиме агента).
- Система авторизации
- Дерево размышлений (в истории промптов можно менять любое сообщение тем самым создавая другую ветку размышлений)
- Работа через API-ключи

### Стек:

- Ktor сервер + клиент
- PostgreSQL для пользователей и чатов
- Модели будут храниться во внутреннем хранилище сервера
- Вложения чатов и изображения будет храниться на S3 (или подобном сервисе)
